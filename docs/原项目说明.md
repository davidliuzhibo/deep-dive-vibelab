# 深海潜航 DeepDive

PICO Project Swan 上的全沉浸游戏：一片海装在玻璃水箱里，坐着开小潜水器一层层往下潜。

> 2026-11-05 v0.1（versionCode 1）：
> - 十二次下潜，三章（阳光和暮光、午夜带、深渊）。
> - 看向水里捏一下潜水器开过去；捏生物或物体，它自己靠近并拍照或采样。
> - 探照灯：越深越黑，只有灯照到的才看得见；胆小的动物要关灯靠近，到了再开灯。电量用完任务失败。
> - 十二种生物和物体，每种第一次拍到时给一条知识，收进「深海图鉴」窗口。
> - 铜、银、金奖杯，金奖杯解锁「万灯之海」。三个窗口：关卡、图鉴、说明。
> - 调试钩子 AutoPilot（logcat 标签 DeepTest）。

## 测试状态

- 单元测试 11 条通过，包括从座位出发的捏合框检查。
- 模拟器：机器人走查 12 次下潜全部三星，进程没有崩溃。
- **没有验证：真实的手部瞄准和捏合。** 走查是直接调用游戏函数的，要在真机上确认。
- **没有验证：真人的难度。** 电量和三星线按机器人的用量定，真人可能偏紧或偏松。

## 构建

```
cd app
JAVA_HOME=~/.pico/primer-cli/jdk/jdk-21.0.12.1+1 ./gradlew --no-daemon testDebugUnitTest assembleDebug assembleRelease
```

素材由 `tools/make_assets.sh` 生成（在外层工作区根目录运行）。安装包复制在 `apk/`。
