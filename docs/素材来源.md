# 素材来源

- 3D 模型（潜水器、十二种生物和海底物体、奖杯）：火山方舟 Seed3D，由本项目自己生成的参考图生成。
- 贴图（实验室全景、海底泥沙）：火山方舟 Seedream 生成。水箱里的海水渐变是程序绘制的。
- 音乐：Deep Sea，作者 umplix，CC0，https://opengameart.org/content/deep-sea
- 音效：`tools/sfx_synth.py` 合成，没有第三方素材。
- 图鉴里的科学知识是普及性内容，提交前建议再核对一遍数字。
